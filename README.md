# Stock Portfolio Tracker

A beginner-friendly Python console project using a dictionary of hardcoded example stock prices.

## Run
1. Extract this ZIP file.
2. Open the folder in Visual Studio Code.
3. Open the terminal and run:

   `python stock_tracker.py`

## Example stock prices
- AAPL: $180
- TSLA: $250
- GOOGL: $140
- AMZN: $190
- MSFT: $420

Enter stock names and quantities to calculate investment value. The program can
also save the result to `stock_portfolio.txt`.

These are example prices for the coding exercise, not live market prices.
